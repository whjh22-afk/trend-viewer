키 설정 처음 한 번만

키는 이 브라우저(localStorage)에만 저장되고, 유튜브 API 요청 외에는 어디로도 보내지지 않습니다. 공용 PC에서는 사용 후 키 칸을 비우고 불러오기를 눌러 저장된 키를 지우세요.

② 불러오기

인기 차트는 유튜브가 고른 상위 영상이고, 직접 검색은 선택한 기간에 올라온 영상 중 조회수 상위 10개를 가져옵니다. 결과는 카테고리마다 최대 10개까지만 보여 줍니다. 인기 차트에서 카테고리를 '전체'로 두면 카테고리별 상위 10개씩 묶어서 보여 줍니다(직접 검색은 사용량이 커서 묶지 않습니다). 경제·AI는 유튜브 공식 카테고리가 아니라 키워드 검색으로 찾습니다. 키워드를 쉼표로 여러 개(최대 5개) 넣으면 키워드별 상위 10개씩 묶어서 보여 줍니다. 직접 검색은 API 사용량을 많이 씁니다(키워드 1개당 약 101).

Apify 토큰 설정 처음 한 번만

① Apify 가입(구글 계정으로 가능) → ② API & Integrations 화면에서 Personal API token 복사 → ③ 위 칸에 붙여넣고 불러오기. 토큰은 이 브라우저(localStorage)에만 저장되고 Apify 요청 외에는 어디로도 보내지지 않습니다.

② 불러오기

카테고리의 대표 해시태그 영상을 40개쯤 모아 정렬한 뒤 상위 10개를 보여 줍니다. 보기 방식은 불러온 뒤에도 바꿀 수 있어요(다시 불러오지 않음). 1~2분 걸릴 수 있어요. 불러올 때마다 Apify 무료 크레딧(매달 제공)이 조금씩 차감되며, 남은 양은 Apify 화면의 Usage에서 볼 수 있습니다. 공식 기능이 아니라서 가끔 실패하면 잠시 후 다시 눌러 주세요.
